# Security policy

Please do not report security vulnerabilities in public issues.

For vulnerabilities in this maintained fork, use GitHub's private **Report a vulnerability** form for [`tandr-ssn/sarif-web-component`](https://github.com/tandr-ssn/sarif-web-component/security/advisories/new). Include the affected commit or release, reproduction steps, expected impact, and a proof of concept when possible.

This repository derives from Microsoft's SARIF Web Component. If the issue also affects the upstream Microsoft project, report it separately to the [Microsoft Security Response Center](https://aka.ms/opensource/security/create-report).

Ordinary defects and feature requests may use the public issue tracker.
